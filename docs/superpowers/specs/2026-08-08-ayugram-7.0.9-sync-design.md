# Design Spec: AyuGram 7.0.9 Release & Fixes Integration

## Overview
Integrate all official upstream updates, bug fixes, and feature enhancements from `https://github.com/AyuGram/AyuGramDesktop` (branch `origin/dev`, including Telegram Desktop v7.0.9 merge) into the local `dev` branch while preserving local custom improvements.

## Proposed Strategy
We will perform a Git merge of `origin/dev` into our local `dev` branch, update submodules, and resolve any code conflicts gracefully.

### Key Upstream Features & Fixes to Sync
1. **Telegram Desktop 7.0.9 Core**: Merge of official `v7.0.9` tag into `dev`.
2. **Rich Message Formatting Enhancements**:
   - Support rich formatted messages in repeat message (`032ad32854`).
   - Support rich messages in AyuForward with fixes (`37d879f206`).
   - Fix rich message editing behavior (`4c23f16ab8`).
3. **Streamer Mode Rework**: Updated streamer mode logic (`130445d9e1`).
4. **Music Widget & Profile Improvements**: Official music widget fix (`9b6ed3e159`) merged with our local smooth profile music animations and zero-shift layout fixes.
5. **Memory & Stability Fixes**:
   - Translator batch memory leak fix (`50893b18f2`).
   - Fix potential crashes in miniapps and messaging popups (`b16a5d57d4`, `91303da6f1`).
   - D-Bus CMake configuration workaround (`8e18cb7110`).
6. **Submodule Updates**: Sync submodules (`lib_ui`, `lib_tl`, `codegen`, `lib_icu`) with upstream commits.

## Conflict Resolution Rules
- If conflict arises in profile music / animation logic: merge upstream fix while retaining local smooth animation slide bounds and background immediate initialization.
- If conflict arises in Rich Messages / AyuForward: adopt upstream rich message engine enhancements.

## Verification Strategy
1. Verify `git merge` completes with zero unresolved conflict markers.
2. Verify submodules are updated and clean (`git submodule update --init --recursive`).
3. Inspect `git log` to confirm `v7.0.9` tag and subsequent upstream commits are present in `dev`.
